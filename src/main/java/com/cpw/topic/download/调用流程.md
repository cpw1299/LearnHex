按照协议（download_data），完整流程:

```text
平台发送download_data
        │
        ▼
SessionManager.create(downloadTaskId)
        │
        ▼
Session(INIT)
        │
        ▼
收到MQTT_RESPONSE（开始）
        │
        ▼
Session.status = RUNNING
        │
        ▼
收到download/data
        │
        ├────────────► StorageListener(TODO保存数据)
        │
        ▼
收到download/info
        │
        ▼
Session.receiveCount++
Session.fileSum=107
Session.currentFilename=xxx.txt
        │
        ▼
继续收到download/data
        │
        ▼
继续收到download/info
        │
        ▼
......
        │
        ▼
收到MQTT_RESPONSE（结束）
        │
        ▼
Session.status=FINISHED
        │
        ▼
SessionManager.remove(taskId)
```


SpringBoot + MQTT 方案：

> MQTT Listener → Dispatcher → Event → DownloadService → SessionManager + StorageService

分层职责最清晰，容易维护和扩展
